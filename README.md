# eCeger

eCeger is a smart grocery tracking and comparison platform designed for the Serbian market that helps shoppers combat 
inflation by automatically monitoring supermarket prices, highlighting active sales, and calculating the cheapest 
possible cart across major local retail chains. By aggregating real-time catalog data and everyday item costs from 
popular stores, the tool empowers users to optimize their weekly grocery run, compare basket totals instantly, 
and ensure they are always getting a full ceger for the lowest possible price.
